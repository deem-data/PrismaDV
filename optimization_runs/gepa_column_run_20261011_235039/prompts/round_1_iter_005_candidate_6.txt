### Definition of "Touches" (Data Lineage & Transitive Taint Tracking)

A line touches the target column if it interacts with the column name, direct data slices, or any downstream intermediate variables derived from it. Taint propagation is **fully transitive and recursive**.

You must include all lines matching any of the following categories:

1. **Column Name String Definitions & Aliases**:
   - String literals of the target column name (e.g., `'col_name'`, `c = 'col_name'`).
   - Data structures (lists, tuples, sets, dicts) containing the column name literal or its string variable (e.g., `cols = [..., c, ...]`).

2. **Loops and Dynamic Selection**:
   - Loops, iterators, or comprehensions that iterate over collections containing the column name (e.g., `for col in cols:`).
   - Loop body statements that dynamically inspect, coerce, or transform the column (e.g., `if c in df.columns: df[c] = pd.to_numeric(...)`).

3. **Data Ingestion, Extraction, and Coercion**:
   - Direct column access, indexing, or slicing from DataFrames/Series (e.g., `df['col']`, `df[c]`, `df[['col', ...]]`, `df.loc[:, col]`).
   - Type conversions, parsing, imputation, and coercions applied directly to the column (e.g., `pd.to_numeric(df[col])`, `.astype(...)`, `.fillna(...)`, `.replace(...)`).

4. **Transitive Downstream Derivations (Full Taint Propagation)**:
   - **Assignments**: Any variable that stores the column's data, slice, or any intermediate calculation derived from it (e.g., `s1 = df[target]`, `ratio = s1 / total`, `risk = 0.5 * ratio + ...`).
   - **Expressions & Operators**: All downstream expressions where a tainted variable appears in arithmetic operations (`+`, `-`, `*`, `/`, etc.), mathematical functions (`np.abs()`, `np.clip()`, `.mean()`), logical conditions, masks, or comparisons (`np.where(...)`, `val > 0`, `.isin(...)`).
   - **Transitive Recursion**: If variable $A$ is tainted by the target column, and variable $B$ is computed using $A$, then $B$ is also tainted. Every line reading, updating, or passing $B$ downstream must be tracked.

5. **DataFrame Assembly, Mutations, and Downstream Persistence**:
   - Lines where tainted Series, arrays, or derived metrics are assigned back into a DataFrame (e.g., `df['score'] = tainted_var`, `out = pd.DataFrame({'feature': tainted_var})`).
   - Slicing, sorting, filtering, or manipulating DataFrames that contain tainted columns or the target column itself (e.g., `out.sort_values(by=['score'])`, `out[out['flag'] == 1]`).
