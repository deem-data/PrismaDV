### Task Instructions
1. **Translate Assumptions to PyDeequ Checks**:
   - Map each assumption to one or more appropriate PyDeequ checks from the provided list of functions.
   - Every check must be linked to the 0-based indices of the assumption(s) it verifies via the `linked assumptions` field.
   - If no assumptions are provided, return an empty list for `"constraint_code"`.

2. **Assign Constraint Severity Levels (`"error"` vs `"warning"`)**:
   - **`error`**: Use for critical data contracts. If a constraint failure would crash downstream execution, produce invalid/corrupted results, or violate a fundamental pipeline invariant, assign `"error"`.
   - **`warning`**: Use for soft data quality expectations or minor anomalies where the code still functions safely and produces acceptable results.
   - **Crucial Rule**: Avoid marking all checks as `"warning"`. A warning-level constraint never rejects a batch. At least one check covering foundational schema/integrity assumptions (e.g., critical types, ranges, completeness, or core valid values) must be set to `"error"` so that bad batches can be caught and flagged.

3. **Code Syntax and Conventions**:
   - Every suggestion string must start with a leading dot (e.g., `.isComplete('column_name')`).
   - Use backticks around column names in SQL expressions inside `.satisfies('`col` >= 0', 'constraint_name')`.
   - For `.hasDataType`, use `ConstrainableDataTypes.<Type>` (e.g., `ConstrainableDataTypes.Numeric`, `ConstrainableDataTypes.Integral`, `ConstrainableDataTypes.Fractional`, `ConstrainableDataTypes.String`, `ConstrainableDataTypes.Boolean`).
   - For regex patterns in `.hasPattern`, always use raw strings (e.g., `r"^\d+$"`).

### Available PyDeequ Functions

#### Row-Level Functions:
- `.isComplete(column)`: Validates column contains no nulls.
- `.hasCompleteness(column, assertion)`: Completeness fraction (0.0 to 1.0) meets lambda threshold.
- `.areComplete(columns)`: All columns in the list contain no null values.
- `.haveCompleteness(columns, assertion)`: Completeness fraction across a set of columns meets assertion.
- `.areAnyComplete(columns)`: At least one column in set is complete.
- `.satisfies(columnCondition, constraintName, assertion=None)`: SQL WHERE clause condition. Example: `.satisfies('`val` >= 0', 'val_non_negative')`.
- `.hasPattern(column, pattern, assertion=None, name=None)`: Regex pattern check using raw strings `r"..."`.
- `.containsCreditCardNumber(column, assertion=None)`: Validates credit card format.
- `.containsEmail(column, assertion=None)`: Validates email format.
- `.containsURL(column, assertion=None)`: Validates URL format.
- `.containsSocialSecurityNumber(column, assertion=None)`: Validates US SSN format.
- `.hasDataType(column, datatype, assertion=None)`: Checks `ConstrainableDataTypes.<Type>`.
- `.isNonNegative(column, assertion=None)`: Numeric values >= 0.
- `.isPositive(column, assertion=None)`: Numeric values > 0.
- `.isLessThan(columnA, columnB, assertion=None)`: columnA < columnB.
- `.isLessThanOrEqualTo(columnA, columnB, assertion=None)`: columnA <= columnB.
- `.isGreaterThan(columnA, columnB, assertion=None)`: columnA > columnB.
- `.isGreaterThanOrEqualTo(columnA, columnB, assertion=None)`: columnA >= columnB.
- `.isContainedIn(column, allowed_values, assertion=None)`: Values are within the specified list.

#### Aggregate-Level Functions:
- `.hasSize(assertion)`: Total row count check. Example: `.hasSize(lambda x: x >= 100)`.
- `.haveAnyCompleteness(columns, assertion)`: At least one column meets completeness threshold.
- `.isUnique(column)`: Every value in the column is distinct.
- `.hasUniqueness(columns, assertion)`: Uniqueness ratio meets assertion.
- `.hasDistinctness(columns, assertion)`: Distinct values ratio meets assertion.
- `.hasUniqueValueRatio(columns, assertion)`: Unique value ratio meets assertion.
- `.hasNumberOfDistinctValues(column, assertion, binningUdf=None, maxBins=1000)`: Distinct count check.
- `.hasMutualInformation(columnA, columnB, assertion)`: Mutual information meets assertion.
- `.hasApproxQuantile(column, quantile, assertion)`: Quantile value meets assertion.
- `.hasMinLength(column, assertion)`: String minimum length meets assertion.
- `.hasMaxLength(column, assertion)`: String maximum length meets assertion.
- `.hasMin(column, assertion)`: Minimum numeric value meets assertion.
- `.hasMax(column, assertion)`: Maximum numeric value meets assertion.
- `.hasMean(column, assertion)`: Mean value meets assertion.
- `.hasStandardDeviation(column, assertion)`: Standard deviation meets assertion.
- `.hasCorrelation(columnA, columnB, assertion)`: Correlation coefficient meets assertion.
